# اپلیکیشن اندروید تشخیص زنده پلاک خودرو با هوش مصنوعی محلی (ONNX + Flet 1.0)

این پروژه یک اپلیکیشن موبایل اندروید به زبان **پایتون** با فریم‌ورک **Flet 1.0** است که:
- تصویر زنده دوربین گوشی اندرویدی را دریافت می‌کند.
- به‌صورت **کاملاً محلی (روی خود گوشی)** با استفاده از مدل‌های هوش مصنوعی **YOLO26** (فرمت `.onnx` در پوشه `src/weights`) پلاک خودروهای ایرانی و ۳۹ کلاس کاراکتر فارسی را مطابق مخزن [Persian_Plate_Recognition](https://github.com/shahabbai/Persian_Plate_Recognition) شناسایی می‌کند.
- بلافاصله پس از تشخیص محلی، **کادر آبی** دور پلاک رسم می‌شود.
- شماره پلاک را به سرور `http://myweb.web.com` ارسال می‌کند:
  - در صورت پاسخ **`NO`**: کادر دور پلاک **قرمز** می‌شود.
  - در غیر این صورت: کادر دور پلاک **سبز** می‌شود.
- صفحه اصلی شامل دو بخش است:
  - **بخش بالا**: نمایش زنده دوربین + کادرهای رنگی و نوار وضعیت (FPS، چراغ قوه، توقف/ادامه اسکن، تنظیمات).
  - **بخش پایین**: نمایش گرافیکی پلاک، اطلاعات دریافتی از سرور و دکمه **«ثبت تخلف»** که با فشردن آن بخش پایینی به فرم **ثبت تخلف خودرو** تغییر می‌کند.

## راهنمای گام‌به‌گام ساخت فایل APK در GitHub Actions (برای افراد کاملاً مبتدی)

1. در سایت [github.com](https://github.com) یک حساب رایگان بسازید.
2. روی **New Repository** کلیک کنید، یک نام دلخواه (مثلاً `persian-plate-app`) انتخاب کنید و دکمه **Create repository** را بزنید.
3. فایل‌های این پروژه را در مخزن آپلود کنید (از طریق دکمه **Add file → Upload files** یا GitHub Desktop).
4. فایل‌های مدل `.onnx` را در پوشه `src/weights/` قرار دهید.
   - **اگر فایل `.onnx` ندارید:** هیچ برنامه‌ای روی کامپیوتر نصب نکنید! فقط وارد تب **Actions** شوید → روی **Build Android APK (Fast Cached)** کلیک کنید → دکمه **Run workflow** را بزنید → تیک گزینه **`auto_export_onnx`** را روشن کنید و **Run workflow** را بزنید. گیت‌هاب به‌صورت خودکار مدل‌های `cars_best_v26.pt` و `chars_best_v26.pt` را به `.onnx` تبدیل، کش و داخل APK قرار می‌دهد.
5. پس از پایان ساخت (علامت تیک سبز)، وارد همان اجرا شوید، به پایین صفحه بخش **Artifacts** بروید و روی **`persian-plate-scanner-android-apk`** کلیک کنید تا فایل ZIP دانلود شود.
6. فایل ZIP را باز کنید، فایل `.apk` داخل آن را به گوشی اندرویدی منتقل کرده و نصب کنید.
7. هنگام اولین اجرا، مجوز **دوربین (Camera)** را تأیید کنید.

## قرارداد API پیشنهادی برای سرور `myweb.web.com`

### ۱) استعلام پلاک (`POST http://myweb.web.com/api/plate/check`)
بدنه ارسالی (JSON):
```json
{
  "plate": "12ب34567",
  "plate_latin": "12B34567",
  "confidence": 0.942,
  "timestamp": "2026-11-14T08:30:00+00:00"
}
```
پاسخ قابل پذیرش توسط اپلیکیشن (متن ساده یا JSON):
- متن ساده `"NO"` یا JSON دارای `"status": "NO"` / `"result": "NO"` / `"allowed": false` ← **کادر قرمز**
- هر پاسخ موفق (`HTTP 200`) غیر از `NO` (مثلاً `"YES"` یا `{"status": "OK", "owner": "...", "car": "..."}`) ← **کادر سبز**

### ۲) ثبت تخلف (`POST http://myweb.web.com/api/violation`)
```json
{
  "plate": "۱۲ ب ۳۴۵ | ایران ۶۷",
  "plate_latin": "12B34567",
  "violation_type": "توقف ممنوع / پارک دوبل",
  "description": "توضیحات مأمور",
  "timestamp": "2026-11-14T08:31:12+00:00",
  "has_image": true,
  "image_base64": "..."
}
```
> نکته: در صورتی که مسیر API سرور شما متفاوت است، می‌توانید هم در فایل `src/config.py` و هم مستقیم از دکمه تنظیمات (⚙️) داخل خود اپلیکیشن آدرس را تغییر دهید.
