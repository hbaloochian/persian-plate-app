# پوشه دارایی‌ها و آیکون اپلیکیشن (`src/assets`)

برای تنظیم یا تغییر آیکون اپلیکیشن اندروید (و صفحه شروع برنامه):

1. تصویر آیکون خود (فایل **`2.png`** با فرمت PNG، ترجیحاً مربعی و با ابعاد `512x512` یا `1024x1024`) را با نام **`icon.png`** در همین پوشه (`src/assets/icon.png`) قرار دهید.
2. **یا به‌صورت خودکار:** فایل **`2.png`** را مستقیماً در ریشه مخزن یا داخل همین پوشه (`src/assets/2.png`) آپلود کنید؛ اسکریپت ساخت GitHub Actions (`build-android.yml`) پیش از ساخت APK به‌صورت خودکار آن را به `src/assets/icon.png` و `src/assets/icon_android.png` تبدیل و اعمال می‌کند.
