# پوشه مدل‌های هوش مصنوعی (`weights`)

فایل‌های مدل هوش مصنوعی با پسوند `.onnx` را در این پوشه قرار دهید:

1. `cars_best_v26.onnx` — مدل مرحله اول: تشخیص خودرو و کادر پلاک
2. `chars_best_v26.onnx` — مدل مرحله دوم: تشخیص ۳۹ کلاس کاراکتر پلاک ایرانی

### چگونه این فایل‌ها را بدون نیاز به نصب هیچ برنامه‌ای روی کامپیوتر بسازید؟
در مخزن گیت‌هاب خود وارد تب **Actions** شوید و یکی از دو روش زیر را انجام دهید:
- **روش ۱ (ساده‌ترین):** روی workflow با نام **Build Android APK (Fast Cached)** کلیک کنید، دکمه **Run workflow** را بزنید و تیک گزینه **`auto_export_onnx`** را فعال کنید. گیت‌هاب به‌صورت خودکار مدل‌ها را تبدیل، کش و داخل فایل APK قرار می‌دهد.
- **روش ۲:** روی workflow با نام **Export YOLO26 ONNX Models** کلیک کرده و فایل‌های `.onnx` تولیدشده را دانلود و در همین پوشه آپلود کنید.
